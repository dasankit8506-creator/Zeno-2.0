# ZENO AI - Live at zeno20.vercel.app

**Built by Ankit Das | Class 11, Kolkata, India**
**Tagline: Understand. Adapt. Improve.**

ZENO is a Multilingual + Vision AI Chatbot - It can talk in every language and can SEE photos and solve questions from photos.

### 🔗 Live Demo
👉 https://zeno20.vercel.app

### ✨ Features
- 🌍 Talks in Every Language (English, Bengali, Hindi, Japanese, etc.)
- 👁️ Vision Power: Upload any photo, ZENO can read and solve it
- 📚 Student Helper: Solves textbook questions from photos
- ⚡ Fast & Free: Powered by Google Gemini API

### 🛠️ Built With
- Google Gemini API (Brain)
- Vercel (Hosting)
- ChatGPT as my teacher
