# ZENO Learning Companion

Build a modern, premium AI web app called ZENO.

Tagline: "Understand. Adapt. Improve."

DESIGN:

A clean, professional AI interface with a dark navy background, white text, cyan accents, and subtle green highlights.

A simple geometric ZENO logo.

A central chat area with a welcome message: "Hello, I'm ZENO. What would you like to explore today?"

A message input at the bottom with a send button.

Three suggested prompts: "Explain something difficult", "Help me solve a problem", and "Explore a new idea".

After every demo answer, show three actions: "Simpler", "Go deeper", and "Check my understanding".

Include a New Chat button and a responsive layout for desktop and mobile.

Make the design feel original, polished, and easy to use.

FUNCTIONALITY:

Make the chat input, send button, suggested prompts, and three adaptive actions interactive.

For now, use clearly labeled demo responses. Do not pretend a real AI model is connected.

Keep the code organized so a real AI model can be connected securely through a backend later.

Never put secret API keys in browser code.

Do not add payments, subscriptions, or unnecessary sign-up screens.

Build the first working front-end version. Prioritize usability and quality over unnecessary animations.
